## Analysis Populations

- Intent-to-evaluate population: all accepted external cases passing intake controls.
- Protocol-complete population: cases without major protocol deviation affecting target endpoint.
- Per-site sensitivity population: protocol-complete population stratified by site profile.

## Statistical Methods

- Continuous reproducibility metrics:
  - Bland-Altman summary,
  - intraclass correlation coefficient (two-way mixed effects, absolute agreement),
  - two-sided 95% confidence interval reporting.
- Binary/proportion endpoints:
  - Wilson score intervals for rates,
  - stratified site-profile summary and pooled estimate.
- Site heterogeneity:
  - random-effects meta-analytic summary for cross-site pooled estimates.

## Missing Data and Deviation Handling

- Missing endpoint values are classified by cause before analysis lock.
- Primary analysis uses protocol-complete population.
- Sensitivity analysis includes intent-to-evaluate population with conservative imputation for missing binary outcomes.
- Cases with security/control violations remain excluded and are reported in deviation ledger.

## Acceptance Boundaries

| Endpoint ID | Acceptance boundary |
|---|---|
| EVP-PE-001 | Lower confidence bound of agreement metric remains within predeclared tolerance profile for claim context |
| EVP-PE-002 | Transaction success rate meets target threshold and invalid-path fail-closed rate remains complete for tested negatives |
| EVP-SE-001 | Provenance completeness rate meets minimum threshold per site profile and pooled cohort |
| EVP-SE-002 | Stability metric remains within approved environment-variance envelope |
